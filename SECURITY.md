# Security policy

Report vulnerabilities privately to **mickael.freitas@sciencespo.fr**.
Do not open public issues containing vulnerabilities, credentials, tokens, or personal data.
Include affected behavior, reproduction steps, and impact with sensitive information redacted.
Please allow time for investigation and a fix before public disclosure.

Never commit real environment files. If a private credential enters Git history,
revoke or rotate it before making the repository public; ignoring or deleting a file
does not remove it from previous commits.
